# Governments and civilization slots

Civilization slot 0 is the Barbarians; slots 1–7 hold the human and computer
players. Slot numbers are separate from tribe-table indices. The same colour
slot can hold one of two tribes; see [Tribes](../ai/civ_identities.md).

| Government ID | Government |
| ---: | --- |
| 0 | Anarchy |
| 1 | Despotism |
| 2 | Monarchy |
| 3 | Communism |
| 4 | Republic |
| 5 | Democracy |

Difficulty ranges from 0 (Chieftain) to 4 (Emperor). Diplomatic relations
use [bit flags](../ai/relations.md) rather than government-style numbered states.
