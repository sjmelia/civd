# Improvement and Wonder Values

Improvement numbers follow the [source improvement table](../city/improvements_wonders.md); the bit for improvement `n` in a city's `buildings` word is `n - 1`. `CIV.H` defines `HAS_PALACE`, `HAS_CITY_WALLS` and `HAS_SDI`.

Wonder names and ordering are documented in the [wonder catalog](../city/improvements_wonders.md).
